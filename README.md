## Node.js setup

This project targets Node.js 20 or later (see `.nvmrc` / `package.json` engines field).

### Install Node.js

**Using nvm (recommended):**

```bash
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/master/install.sh | bash
# restart your shell, then:
nvm install
nvm use
```

**Direct install:** download an installer from [nodejs.org](https://nodejs.org/).

### Verify

```bash
node -v
npm -v
```

### Install project dependencies

```bash
npm install
```
